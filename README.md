# Codeforces Solutions

This repository contains my solutions to Codeforces problems, primarily solved during programming contests.

## Language
- C++

## Organization
Solutions are organized by contest, with each problem stored in a separate `.cpp` file named according to its problem index.

## Purpose
- Practice competitive programming.
- Improve problem-solving and algorithmic thinking.
- Track my progress across Codeforces contests.
- Prepare for software development engineering interviews.

## Platform
[Codeforces](https://codeforces.com/)

This repository is updated as I solve more problems.
